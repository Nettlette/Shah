  1. Problem 1: Calculate the Factorial Write a function named calculate_factorial(n) that takes a non-negative integer n and returns its factorial (n!). The factorial of a number is the product of all positive integers less than or equal to n (e.g., 5! = 5 x4 x3 x2 x1 = 120). Requirements: If n is 0, return 1 (since 0! = 1). Use a for or while loop to multiply the numbers together. Requirements: The count should be case-insensitive (e.g., 'A' and 'a' both count). Loop through each character in the string to check if it is a vowel. Example Input: count_vowels("Hello World")

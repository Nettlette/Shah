Homework 1

Problem 1: Calculate the Factorial

Write a function named calculate_factorial(n) that takes a non-negative integer n and returns its factorial (\(n!\)). The factorial of a number is the product of all positive integers less than or equal to n (e.g., \(5! = 5*4*3*2*1 = 120\)).

Requirements:
  • If n is 0, return 1 (since 0! = 1).
  • Use a for or while loop to multiply the numbers together.
Example Output: (User input in red)

Enter a number: 5

120

Problem 2: Count the Vowels

Write a function named count_vowels(text) that takes a string as input and returns the total count of vowels (a, e, i, o, u) present in it.

Requirements:
  • The count should be case-insensitive (e.g., 'A' and 'a' both count).
  • Loop through each character in the string to check if it is a vowel.
Example Input: (User input in red)

Enter a string: hello world!

Vowels: 3

Problem 1: Fruit Stand

WRite a Python program that helps a fruit stand customer check prices and calculate their total bill.

Tasks:
  • Create a dictionary named fruit_prices with the following items and prices:
    • Apple: 1.50
    • Banana: 0.75
    • Orange: 1.25
    • Mango: 2.00
  • Ask the user to enter the name of a fruit they want to buy.
  • Check if the fruit is in the dictionary:
    • If it is in the dictionary, print its price, and ask the user how many they want to buy, and calculate the total cost for that item.
    • If it is not in the dictionary, print a message saying "Sorry, we do not have that fruit!"
Example Output: (User input in red)

Enter a fruit you want to buy: Apple

An Apple costs $1.5

How many would you like to buy? 3

Your total cost is $4.50


Example Output: (User input in red)

Enter a fruit you want to buy: Dragonfruit

Sorry, we do not have that fruit!


Hints:
  • Use .lower() or .capitalize() to make sure matching works even if the user types in lowercase.
  • Use in to check if a key exists in your dictionary before looking up its value.
  • Don't forget to convert the user's quantity input to an integer.

Problem 2: Classroom Gradebook

Write a Python program that calculates student averages for a teacher's gradebook without crashing when bad input is entered.

Tasks:
  • Create a dictionary named gradebook where the keys are student names and the values are empty lists
    gradebook = {"Alex": [], "Taylor": [], "Jordan": []}
  • Write a loop that continuously asks the user to enter a student's name (Alex, Taylor, or Jordan).
    • If the user types in "quit", the loop should stop.
    • If the student name is not in gradebook, print "Student not found!" and ask again.
  • Once a valid student is chosen, prompt the user to enter a test score (0-100) and convert it to a float.
  • Handle Exceptions (try/catch):
    • If the user enters something that isn't a number (like "eighty" or "absent"), catch the ValueError and print "Invalid score! Please enter a numeric grade."
    • If a valid float is entered, append it to that student's list in gradebook.
  • After the user quits, print out each student's name along with their average test score.
    • Handle Zero Division (try/except): When calculating the average (sum/len), catch the ZeroDivisionError if a student has no grades entered, and print "No grades recorded" instead of an average.

Example Input: (User input in red)

Enter a student name (or 'quit' to finish): Alex

Enter grade for Alex: 85

Grade added!

Enter a student name (or 'quit' to finish): Alex

Enter grade for Alex: ninety

Invalid score! Please enter a numeric grade.

Enter a student name (or 'quit' to finish): Jordan

Enter grade for Jordan: 100

Grade added!

Enter a student name (or 'quit' to finish): quit

--- Final Averages ---

Alex: 85.0

Taylor: No grades recorded

Jordan: 100.0


Hints:
  • Wrap float(input(...)) inside a try block to catch ValueError.
  • WRap your average calculation inside a try block to catch ZeroDivisionError.
